# DECISIONS

## [2026-08-06] TodayP/L% 与 Chg% 去重；中英界面切换；`h` 快捷键提示

**背景**
mode 3 的 `TodayP/L%` 与基础列 `Chg%` 数值完全相同（今日收益率 = 现价相对昨收的涨跌幅），冗余一列。中文用户需要界面切换。快捷键只在 README 里有说明，界面内无法发现。

**决策**
- 删除 mode 3 的 `TodayP/L%` 列，只保留 `TodayP/L`（今日收益额，与 `Chg` 涨跌额不重复）。模式 3 共 14 列。
- 语言切换：默认英文（维持伪装），`~/.bosskey.toml` `[display] lang = "en"` 设初始语言；TUI 内按 `l` 会话内切换（不持久化，与 `t`/`b` 一致）；CLI 加 `--lang {en,zh}` 覆盖、`--list-langs` 列出。
- `h` 键开关底部快捷键提示行（默认隐藏，灰色低调，维持极简；内存态不持久化）。
- 文案统一走新模块 `bosskey_stock/i18n.py`（key → (en, zh) 对照表），TUI（表头/状态栏/底部汇总/快捷键提示）与 CLI（add/rm/list/pos 输出、pos add 交互提示、--help）全部覆盖。
- 老板模式日志主体保持英文 Docker 命令（翻译反而穿帮），仅底部 `Running time:` 本地化为 `运行时间:`。

**理由**
- TodayP/L% 即 Chg% 是数学恒等式，保留是信息冗余、占用列宽。
- 默认英文延续「伪装设计」决策；中文只在用户显式切换时出现，兼顾可读与伪装。
- i18n 单模块集中管理文案，新增语言只需扩展对照表。
- 快捷键提示默认隐藏，避免与「伪装」冲突，按需 `h` 唤出。

**备选方案**
- mode 3 保留 TodayP/L%（与基础 Chg% 重复）— 否，用户明确要求去重。
- 语言仅配置持久化、TUI 无热键 — 否，会话内即时切换更顺手。
- 老板模式日志整体中文化 — 否，Docker 命令中文化违反伪装场景的真实感。
- 帮助常驻显示 — 否，多一行灰色文字破坏极简与伪装；按需开关更合适。

## [2026-08-01] 全英文 UI + 底部持仓汇总随 `t` 切换

**背景**
中文一眼可读，不符合摸鱼伪装；持仓数据分散在表格列里，缺少组合维度的总览。

**决策**
- 界面与 CLI 交互全部英文：表头、状态栏 `Cols:`、`pos add` 交互提示、`add/rm/list` 输出。
- 底部新增汇总行随 `t` 切换：mode≥1 显示 `Value/Cost`，≥2 追加 `HoldP/L`，≥3 追加 `TodayP/L`（均为英文标签）。
- 今日收益率分母用昨日市值（Σ 昨收×股数），昨收缺失退回总成本。

**理由**
- 英文非母语不能一眼读懂，强化「在工作」伪装；与 `b` 键老板模式同一设计哲学。
- 底部汇总给组合总盈亏，收益方向红绿着色。

**备选方案**
- 仅翻译交互提示、其余保留中文 — 否，伪装不彻底。
- 汇总固定全显 — 否，随模式渐进展示，避免模式 0 时信息过载。
